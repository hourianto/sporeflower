Build dependency: xyz.wagyourtail.jvmdowngrader Gradle plugin, version 2.0.1

The build transforms the engine and plugin for Java 8 and relocates/minimizes
the required compatibility classes. Sporeflower's own source remains under
its existing Apache 2.0 license. To rebuild or replace the compatibility
classes, build this source checkout with ./gradlew jar; the intermediate,
untransformed jars are retained under each project's build/intermediates/java17.
The dependency version and transformation tasks are configured in build.gradle.
